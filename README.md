# ANUJ Portfolio

Tech stack: React (Vite)

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Edit content

Update portfolio links, project cards, skills, experience, and certifications in:

```bash
src/portfolioData.js
```

Replace `public/Anuj_Resume.pdf` with the final resume PDF when ready.
